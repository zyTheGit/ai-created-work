#### 练习 12：Hook 自动化审查配置

```

   创建 .husky/pre-commit：
   #!/bin/sh
   npm run lint
   npm run type-check

   在项目 .claude/settings.json 中：

           ]
         }
       ]
     }
   }

4. 测试 Hook 是否生效
   - 编辑一个文件，观察是否自动 lint
   - 提交代码，观察是否自动检查

## Phase 7：Function Calling 与 Agent（第 5-7 个月）

```
操作步骤：
1. 项目初始化（Claude Code）
   > /plan
   > 创建一个智能工作助手 Agent：
   - 基于对话助手扩展
   - 新增：Function Calling、多工具支持
   - 工具：天气查询、网页搜索、计算器、数据库查询

2. 工具定义
   > 使用 Vercel AI SDK 的 tool() 定义以下工具：
   - get_weather：天气查询
   - web_search：网页搜索
   - calculator：数学计算
   - query_database：数据库查询（只读）

   - 用户问题 → LLM 判断需要哪些工具

   - LLM 基于结果生成回答
   - 支持多步工具调用（maxSteps: 5）

   > 在前端展示工具调用过程：
