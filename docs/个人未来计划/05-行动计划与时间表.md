## 二、每周时间预算

```
工作日：每天 1 小时（共 5 小时）
  ├── 30 分钟：学习（阅读/视频/文档）
  └── 30 分钟：实践（写代码/做练习）

周末：每天 2-3 小时（共 5 小时）
  ├── 1 小时：深度学习
  ├── 1 小时：项目实战
  └── 1 小时：总结输出

每周总计：10 小时
每月总计：40-44 小时
```

## 七、每周执行模板

### 周一：规划
```
□ 回顾上周完成情况
□ 确定本周 3 个核心任务
□ 分配到每天的时间段
```

### 周二-周四：执行
```
□ 工作日：30 分钟学习 + 30 分钟实践
□ 记录学习笔记
□ 遇到问题及时记录
```

### 周五：实践
```
□ 专注项目实战
□ 将本周学到的知识应用到项目中
□ 代码提交 + 文档更新
```

### 周末：深度 + 输出
```
□ 2-3 小时深度学习或项目实战
□ 30 分钟总结本周学习
□ 产出：博客/笔记/代码
□ 规划下周任务
```

## 九、风险与应对

| 风险 | 可能性 | 影响 | 应对策略 |
|------|--------|------|----------|
| 工作太忙没时间学习 | 高 | 高 | 利用碎片时间，降低每日目标，保证最小投入 |
| 学习内容太多，不知从何开始 | 中 | 中 | 严格按路线执行，不贪多 |
| 学了用不上 | 中 | 高 | 优先学与工作相关的，学完立刻应用 |
| 技术更新太快 | 低 | 中 | 关注核心原理而非具体实现，原理不易过时 |
| 缺乏动力 | 中 | 高 | 设定小目标+奖励，加入学习社群，公开承诺 |

---

> 💡 计划的价值不在于完美，而在于执行。每周至少完成 70% 的计划就是成功。如果某周只完成了 30%，不要自责，调整下周计划继续前进。
